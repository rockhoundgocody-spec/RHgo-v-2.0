## 2026-08-18 - Remove DangerouslySetInnerHTML in Chart Component Style Generator
**Vulnerability:** Use of `dangerouslySetInnerHTML` in `<ChartStyle>` permitted unescaped HTML/CSS injection via dynamic chart IDs, configuration keys, or CSS variable color values.
**Learning:** Injecting stringified CSS directly into DOM style tags using `dangerouslySetInnerHTML` bypasses React's automatic JSX text escaping. If any part of the CSS selector, key, or property value stems from dynamic or user-controlled inputs without validation, attackers can break out of the style tag (`</style><script>...</script>`) or inject CSS rules.
**Prevention:** Avoid `dangerouslySetInnerHTML` for inline `<style>` tags when generating standard CSS rules. Filter and sanitize selector IDs and variable names using strict alphanumeric whitelist regexes, validate property values against dangerous CSS syntax breaks or tag characters (`;{}<>\r\n\\"'/*`), and render the sanitized CSS string directly as standard React element children (`<style>{cssText}</style>`), which React escapes properly.
