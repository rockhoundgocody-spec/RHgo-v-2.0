## 2026-10-31 - WeakMap Caching for Database-driven Lookup Tables
**Learning:** In React components that regularly fetch read-only lookup data (like the list of `minerals` from `useEntityList`) and associate them with mutated client-side lists (like user `specimens`) inside `useMemo`, constructing Map lookup tables from the static list on every mutation can cause unnecessary garbage collection overhead and render latency. Since the database data array reference remains stable across renders thanks to query caching, caching the computed Map in a module-level global `WeakMap` avoids rebuild iterations completely.
**Action:** Always key a module-level `WeakMap` with the referentially stable database data array when building lookup tables inside components or hooks, completely bypassing repeated iteration passes when target arrays have not fetched new data.
