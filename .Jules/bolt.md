## 2025-02-15 - Caching Referentially Stable API Lists with WeakMap
**Learning:** React components that consume shared query lists (e.g., all minerals or all locations) often build lookup maps inside `useMemo` hooks. If other dependencies of the `useMemo` (such as `specimens` or filter states) change frequently, the hook executes on every change, repeatedly running an expensive O(N) loop to rebuild the lookup map. Because the list fetched from TanStack Query is referentially stable while cached, a global module-level `WeakMap` can store pre-computed lookup Maps using the query array as a key, dropping lookup retrieval to O(1) time and eliminating redundant O(N) loop executions completely.
**Action:** When a component is rebuilding an index or map from a stable list returned by `useEntityList` or other query hooks, introduce a module-level `WeakMap` cache to store and retrieve the pre-computed index.
