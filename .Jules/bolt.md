## 2025-02-18 - Caching Database Array Lookup Tables with WeakMap
**Learning:** React component re-renders often cause useMemo computations to execute repeatedly when parent dependencies change reference. When rendering dashboards or charts (such as CrystalSystemInsights) that map over large database collections (like `minerals` fetched via `useEntityList`), building search lookup Maps on every render can cause measurable lag on complex layouts. By caching the pre-computed `Map` inside a module-level global `WeakMap` keyed by the referentially stable database array, we get O(1) cache hit retrieval and bypass loop execution completely across subsequent re-renders until the underlying data is actually refetched.
**Action:** Always check for rebuilding loops of query-cached lists inside hooks, and use module-level global `WeakMap` objects keyed on the list itself to cache lookup maps or structured representations.
