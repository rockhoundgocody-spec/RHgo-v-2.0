## 0. Headline Finding — the public door is a login wall, not the marketing site

The live root URL (`rhgo.base44.app/`) renders the **login card**, not the
`Landing.jsx` marketing page. The app is configured auth-required, so an
unauthenticated visitor is bounced to `/login` before they ever see the hero,
features, stats, or "Try Full Demo" CTA that `Landing.jsx` was built to show.

This is the single biggest funnel leak in the product: a beautiful, conversion-
oriented landing exists but is unreachable by the public. Every audit grade
below that touches acquisition is capped by this.

**Action (P0):** Make the app public (or add a public `/` route that renders
`Landing` for unauthenticated visitors, with login only on protected routes).
The guest `/demo` route already proves a no-auth path is intended.

## 3. Critical issues, ranked

### P0 — blocks growth or revenue
1. **Public entry is a login wall.** Make Landing the unauthenticated root.
2. **Stripe not wired.** `Pricing.jsx` has `priceId: null`, no `createCheckoutSession`
   function exists, `useSubscription` gates nothing in `Scan.jsx` (no "5 scans/day"
   enforcement). The entire $4.99/$8.99 tier is presentation only.
3. **Inflated marketing stats** (1,400+ hotspots vs 378; 98% accuracy unverified).
   Correct them — authenticity is the brand's moat.

### P1 — product quality / retention
4. **Unbounded `list()` calls** in `Explore` (Specimen) and `seedSpecimenImages`
   (Mineral, TrainingCandidate). Will degrade as data grows. Add limits + pagination.
5. **Community & Market are empty with no cold-start plan.** Seed curated finds,
   add a first-post nudge in onboarding, surface "recent finds" on Hub.
6. **Kid mode is decorative.** `rhgo_mode` localStorage flag is set but nothing in
   Hub/Scan/Explore reads it. COPPA-aware policy ≠ adaptive UX.
7. **Only 6 badge definitions** for 362 minerals — the "Liquid Mineral Badge"
   signature system is thin; rarity-tied unlocks are mostly stubs.

### P2 — polish / consistency
8. **Aesthetic split:** Hub/Scan/Explore use `LiquidMetalOrb`, glass-panel, HUD;
   Landing/Onboarding use emoji (🪨🪨) orbs. Unify on the liquid-crystal system.
9. **Accessibility:** pervasive `text-white/20`, `/25`, `/30` on dark fails WCAG AA
   contrast; several icon-only buttons in Scan/Hub lack `aria-label`.
10. **Family/Expedition co-op** is listed in Pricing features but no family-account
    entity or flow exists in `base44/entities`. Either build it or remove the claim.
11. **`seedSpecimenImages` "skipped" count is misleading** — it conflates "already
    full" with "deferred to next batch." Minor, but the hourly schedule will run
    ~120 times to seed all 362 minerals; consider a daily cadence now that the
    timeout is fixed.

## 4. What's genuinely strong (protect these)
- **Clover companion system** — mood, energy, streak, XP, daily CompanionLog
  snapshots, voice with speak-once guards, the new liquid-metal orb. This is the
  emotional core and the most defensible, ownable part of the product.
- **Scan AI prompt design** — multi-angle, explainable, with lookalikes,
  verification tests, Macrostrat geology context, and calibrated confidence.
- **Privacy posture** — RLS on every entity, geo-privacy tiers in the save flow,
  Stealth Mode, delete-account flow. Policy is best-in-class.
- **Explore depth** — land-access layers, collection-gap detection, expedition
  planner, weather, geology, AR spawns, HUD mode, heat map. Feature-rich.

## 5. Recommended next sprint (highest leverage)
1. Flip the app to public so `Landing` is the entry point. (1 change, huge impact)
2. Connect Stripe via `suggest_payments_installation` + add a
   `createCheckoutSession` backend function; enforce the free-tier scan limit
   in `Scan.jsx` using `useSubscription`.
3. Correct landing stats to real numbers (378 hotspots, " calibrated confidence"
   not "98% accuracy").
4. Add `limit` + cursor pagination to the Explore/Specimen and seeder list calls.
5. Seed 10–20 curated community posts and 5–10 market listings so the social
   surfaces aren't empty on first real-user visit.
6. Wire `rhgo_mode` into a real adaptive layer (simpler copy, bigger tap targets,
   no trade/market) or remove the kid-gate pretense.
