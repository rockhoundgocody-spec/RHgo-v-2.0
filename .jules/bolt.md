## 2026-08-05 - WeakMap Database Lookup Caching
**Learning:** React `useMemo` hooks often depend on a combination of stable fetched list data (e.g., `minerals`) and volatile dynamic user data (e.g., `specimens`). When the dynamic data changes, the hook re-executes, rebuilding any O(N) lookup Maps from the fetched list from scratch. Using a module-level global `WeakMap` keyed by the fetched list array reference completely avoids rebuilding these lookup Maps, reducing the reconstruction cost to O(1) across component re-renders and tab switches without causing memory leaks.
**Action:** When a hook builds an intermediate lookup Map or index from a referentially stable array fetched via a data query, store the built Map inside a global module-level `WeakMap` keyed by the fetched array reference.
