# RHGO Build Directive

This repo is the active build target for RockHound-GO V2.

## Primary build scope

Ship the core loop first:

1. Explore
2. Scan
3. GeoDex / Collection
4. Auth / Profile
5. Safety and legal access
6. Offline status and queued sync

## Product identity

RockHound-GO is a field intelligence and geological adventure platform. It should feel premium, scientific, ethical, rugged, and discovery-driven.

## Implementation priority

- Keep the MVP shippable.
- Make Scan the reveal moment.
- Rename or position Collection as GeoDex where appropriate.
- Add ethical discovery choices after scan.
- Add XP, rarity, discovery chains, stewardship, and offline indicators.
- Treat Community, Market, Clover, AR, and land-access modules as roadmap/demo layers until implemented.

## Guardrails

- Do not encourage illegal collecting.
- Do not expose exact public locations by default.
- Use privacy controls for find locations.
- Make access status visible.
- Mark future features clearly as roadmap unless real.
